    The book in GitHub

    Checking the repo…

    The book is kept in your repo as data/ledger.json. Anyone opening the page reads it. To write back from the browser, add a fine-grained token with Contents: read and write on this one repo — it stays in this browser and is never put in the book or the repo.

    No token? Copy the book and paste it into the file on github.com.

    The crew

    Six sea creatures come with the app. Add your own pictures and they take over the porthole instead — one at random on every load. Pictures stay on this device (shrunk to 220px and kept in this browser); they are never written into the book, the repo, or anywhere else. To put pictures on every device, drop the image files into data/characters/ in the repo and list them in data/characters/index.json.
